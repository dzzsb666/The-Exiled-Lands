# 流放之地交互地图 · 中文核对版

**2026-10-15 用户验收更正：任务只有中文翻译，其余必须完全复刻原站。当前图标、UI和地图渲染存在自行设计，尚未达到要求。后续以 [项目约束](AGENTS.md) 为准；[复刻验收](design-qa.md) 当前为 blocked，下面的功能描述不代表原站保真度通过。**

`codex/source-fidelity` 分支新增原版素材中文核对页：启动后访问 `/review/index.html`。它使用用户提供的原站HTML、CSS、真实字体、标记图集、原生点位坐标与地图引擎，排除广告和追踪。已保存的57个素材文件及构建脚本一并提交，执行 `npm run build` 会重建此页面。

当前仅有默认视野的24张z12瓦片，其他区域和缩放层级缺图；原站账号后台和外部媒体也未离线实现，因此核对页尚未替换首页。原来的React首页仅作为旧实现保留。完整状态见 [复刻验收](design-qa.md)，英文参照见 [reference](reference/README.md)。

Vite + React + TypeScript + Leaflet。部署到 Vercel，地图底图和点位数据随网站发布；运行时不依赖第三方地图接口。

支持地图拖动缩放、64类点位筛选、中英名称/游戏网格/ID搜索、点位深链接、探索进度、备注、个人标记、备份导入导出和移动端筛选抽屉。筛选及名称显示偏好会保留，进度保存在浏览器本地，导入会合并已有记录。资源采集点采用用户确认的中文名称和可区分的类别颜色。

## 中文核对

`data/translations.json` 保存此前已验收地图中的中文名称及来源；`data/point-overrides.json` 保存单点的配方/三星类别显示名称；`data/categories.json` 保存分类译名。

未确认的名称保留英文，界面标为待核对。用户在本会话确认的职业、宠物、营地名称已应用。`data/pending-translations.csv` 可用 Excel 打开；按 CSV 完成核对后，把确认结果写入上述 JSON，运行 `node scripts/build-data.mjs`。没有自动翻译流程。

## 部署

在 Vercel 导入本仓库，框架 Vite，构建命令 `npm run build`，输出目录 `dist`。不需要环境变量或数据库。已提供 `vercel.json`。连接仓库后，生产分支更新会触发构建。

用户最新要求：Vercel步骤由用户自行处理，后续只完善地图并推送GitHub。当前仓库里的最新改进没有继续部署。早期静态核对版的发布状态见 [部署记录](docs/DEPLOYMENT.md)，不会自动跟随本仓库更新。

## 数据边界

导入本地保存的 MapGenie 流放之地快照，共 2,812 个点位。保留原始 ID、英文标题和投影坐标；未重新采集原站的最新数据。网页的原始程序、账号系统、评论、付费功能、长篇说明及说明图片未复制。

底图取自 Funcom 官方论坛公开的 4000×4000 图片。MapGenie 坐标通过此前按十个方尖碑拟合的变换投影，控制点最大误差约 13 像素；这不是游戏客户端实测。点位名称的沿用来源不等于所有名称已经逐项核准。档案馆候选30项在此前被用户指出有误，未作为确认内容导入。
