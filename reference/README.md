# 去广告原站参照

本目录只包含用户2026-10-15提供的HTML和HAR里筛出的公开地图资料，作为英文视觉和交互参照。HAR、请求头、Cookie、用户凭据、广告/统计/追踪脚本均不在此目录。所有动态资源地址改为本地，以CSP禁止第三方资源加载。

`index.html`、`offline-config.js` 和 `source/` 保留原站布局、字体、标记图集、地图引擎和公共点位数据。修改仅涉及：移除广告、改为本地资源地址、把远程搜索改为本地点位检索、以空函数代替原站统计调用。

地图素材仅有z12的24张瓦片，覆盖默认视野，未覆盖全部地图。其他层级和区域缺图会返回404。本目录及其生成的中文页面均不代表完整网站已经还原。原站账号/PRO后台、外部媒体、其他地图没有离线实现。

在本目录运行任意本地静态服务器可查看英文参照；从项目根目录执行 `npm run build:review`，生成中文页面 `public/review/index.html`。译名来自 `public/data/map.json`，界面用语来自 `data/interface-translations.json`；没有确认的游戏文本保留英文。

若需从用户新提供的HAR重建参照，先运行 `scripts/extract-reference-har.py`，再运行 `scripts/build-offline-reference.py`，检查 `.qa/replay/` 后把经过核对的文件更新到本目录。脚本全程离线，不获取任何远端资源。
